# SEIF TRANSLATOR

موقع ترجمة مستقل + إضافة متصفح Chrome / Edge.

## الموقع المستقل
- افتح `index.html` أو انشر المستودع عبر GitHub Pages.
- واجهة داكنة متجاوبة مع الوضع النهاري.
- ترجمة النصوص، واستخراج النص من الصور، وقراءة ملفات TXT وPDF وDOCX.
- اختيار لغات ولهجات، مع زر لعكس لغة المصدر والهدف.
- سجل الترجمات والمحفوظات محفوظان محلياً في المتصفح.
- الترجمة القياسية تستخدم نقطة Google Translate العامة غير الرسمية؛ ليست تكاملاً رسمياً وقد تتغير أو تفرض حدوداً.
- ترجمة اللهجات تستخدم OpenAI API عند تفعيل خيار اللهجات وإضافة مفتاح API من الإعدادات. المفتاح يُخزن محلياً في المتصفح، لذلك لا تستخدمه على جهاز مشترك أو غير موثوق، وقد تترتب تكلفة حسب حساب مزود الخدمة.
- دعم اللهجات يعتمد على النموذج المتصل، وقد تختلف الدقة حسب اللهجة والسياق.

## إضافة المتصفح
1. نزّل ZIP وفك ضغطه.
2. افتح `chrome://extensions` في Chrome أو `edge://extensions` في Edge.
3. فعّل وضع المطوّر.
4. اضغط تحميل إضافة غير مضغوطة وحدد مجلد الإضافة.
5. ثبّت الإضافة في شريط المتصفح.

## حدود النسخة الحالية
- ترجمة الصور في الموقع تستخرج النص وتترجمه؛ لا تعيد رسم النص المترجم داخل الصورة حالياً.
- ترجمة المستندات تستخرج النص من PDF وDOCX وTXT وMD؛ لا تحافظ على تنسيق المستند الأصلي عند الترجمة.
- وضع مواقع الويب يوجه المستخدم إلى إضافة المتصفح لترجمة الصفحة الحالية داخلها؛ لا يقوم الموقع المستقل بجلب صفحات المواقع الخارجية بنفسه.
- استخراج النص من الصور ومعالجة PDF/DOCX يعتمد على مكتبات خارجية تُحمّل عند الحاجة.
- لم يتم بعد اختبار الموقع على جميع المتصفحات والأجهزة أو إجراء اختبارات ترجمة شاملة للهجات.

## الخصوصية
- سجل الترجمات والمحفوظات ومفتاح API تُحفظ في تخزين المتصفح المحلي.
- لا ترفع صوراً أو مستندات حساسة إلى خدمات خارجية إذا لم تكن موافقاً على شروطها وسياسة الخصوصية الخاصة بها.


## نشر الموقع الحقيقي
تمت إضافة سير عمل GitHub Actions للنشر التلقائي. لتفعيل النشر لأول مرة:
1. افتح تبويب Settings في المستودع.
2. افتح Pages.
3. ضمن Build and deployment اختر GitHub Actions كمصدر.
4. افتح تبويب Actions وتأكد من نجاح مهمة Deploy SEIF TRANSLATOR.
بعد نجاحها سيظهر رابط الموقع في إعدادات Pages، وأي تحديث لاحق على فرع main سيُنشر تلقائياً.


## اللهجات والأنواع الإقليمية
يدعم الموقع ملفات توجيه مخصصة لـ 23 نوعاً إقليمياً: التونسية، المصرية، المغربية، الجزائرية، اللبنانية، السورية، الأردنية، الفلسطينية، العراقية، السعودية، الإماراتية، اليمنية، السودانية، العُمانية، الكويتية، القطرية، البحرينية، الليبية، الفرنسية الكندية، الإنجليزية الأمريكية، الإنجليزية البريطانية، الإسبانية المكسيكية، والبرتغالية البرازيلية.

- لكل نوع إقليمي تعليمات منفصلة للمصدر والهدف وأمثلة إرشادية في `dialects.js`.
- يلزم إدخال مفتاح OpenAI API في إعدادات الموقع لتشغيل محرك اللهجات. من دون المفتاح سيظهر خطأ واضح بدلاً من إظهار ترجمة عامة على أنها لهجة.
- هذا الموقع الثابت لا يخفي مفاتيح API داخل المتصفح؛ احتفظ بمفتاحك على جهاز موثوق فقط.
