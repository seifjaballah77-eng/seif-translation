# SEIF TRANSLATOR

موقع ترجمة مستقل + إضافة متصفح Chrome / Edge.

## الموقع المستقل
- افتح `index.html` أو انشر المستودع عبر GitHub Pages.
- واجهة داكنة متجاوبة مع الوضع النهاري.
- ترجمة النصوص، واستخراج النص من الصور، وقراءة ملفات TXT وPDF وDOCX.
- اختيار لغات ولهجات، مع زر لعكس لغة المصدر والهدف.
- سجل الترجمات والمحفوظات محفوظان محلياً في المتصفح.
- الترجمة القياسية تستخدم نقطة Google Translate العامة غير الرسمية؛ ليست تكاملاً رسمياً وقد تتغير أو تفرض حدوداً.
- ترجمة اللهجات تستخدم خادماً وسيطاً آمناً يتصل بـ OpenAI. لا يوضع مفتاح API داخل المتصفح أو في مستودع GitHub.
- دعم اللهجات يعتمد على النموذج المتصل، وقد تختلف الدقة حسب اللهجة والسياق.

## إضافة المتصفح
1. نزّل ZIP وفك ضغطه.
2. افتح `chrome://extensions` في Chrome أو `edge://extensions` في Edge.
3. فعّل وضع المطوّر.
4. اضغط تحميل إضافة غير مضغوطة وحدد مجلد الإضافة.
5. ثبّت الإضافة في شريط المتصفح.

## حدود النسخة الحالية
- ترجمة الصور في الموقع تستخرج النص وتترجمه؛ لا تعيد رسم النص المترجم داخل الصورة حالياً.
- ترجمة المستندات تستخرج النص من PDF وDOCX وTXT وMD؛ لا تحافظ على تنسيق المستند الأصلي عند الترجمة.
- وضع مواقع الويب يوجه المستخدم إلى إضافة المتصفح لترجمة الصفحة الحالية داخلها؛ لا يقوم الموقع المستقل بجلب صفحات المواقع الخارجية بنفسه.
- استخراج النص من الصور ومعالجة PDF/DOCX يعتمد على مكتبات خارجية تُحمّل عند الحاجة.
- لم يتم بعد اختبار الموقع على جميع المتصفحات والأجهزة أو إجراء اختبارات ترجمة شاملة للهجات.

## الخصوصية
- سجل الترجمات والمحفوظات تُحفظ محلياً في المتصفح. مفتاح OpenAI يجب أن يبقى في متغير سري على الخادم فقط.
- لا ترفع صوراً أو مستندات حساسة إلى خدمات خارجية إذا لم تكن موافقاً على شروطها وسياسة الخصوصية الخاصة بها.


## نشر الموقع الحقيقي
تمت إضافة سير عمل GitHub Actions للنشر التلقائي. لتفعيل النشر لأول مرة:
1. افتح تبويب Settings في المستودع.
2. افتح Pages.
3. ضمن Build and deployment اختر GitHub Actions كمصدر.
4. افتح تبويب Actions وتأكد من نجاح مهمة Deploy SEIF TRANSLATOR.
بعد نجاحها سيظهر رابط الموقع في إعدادات Pages، وأي تحديث لاحق على فرع main سيُنشر تلقائياً.


## اللهجات والأنواع الإقليمية
يدعم الموقع ملفات توجيه مخصصة لـ 23 نوعاً إقليمياً: التونسية، المصرية، المغربية، الجزائرية، اللبنانية، السورية، الأردنية، الفلسطينية، العراقية، السعودية، الإماراتية، اليمنية، السودانية، العُمانية، الكويتية، القطرية، البحرينية، الليبية، الفرنسية الكندية، الإنجليزية الأمريكية، الإنجليزية البريطانية، الإسبانية المكسيكية، والبرتغالية البرازيلية.

- لكل نوع إقليمي تعليمات منفصلة للمصدر والهدف وأمثلة إرشادية في `dialects.js`.
- يلزم إدخال مفتاح OpenAI API في إعدادات الموقع لتشغيل محرك اللهجات. من دون المفتاح سيظهر خطأ واضح بدلاً من إظهار ترجمة عامة على أنها لهجة.
- هذا الموقع الثابت لا يخفي مفاتيح API داخل المتصفح؛ احتفظ بمفتاحك على جهاز موثوق فقط.

 
## تحديثات OCR والواجهة متعددة اللغات
- أضيف تحديد منطقة نص داخل الصورة بالسحب بالماوس أو اللمس، مع أزرار تحديد الصورة كاملة وإلغاء التحديد.
- تتم معالجة المنطقة المحددة فقط، مع تكبيرها وتحسين تباينها قبل OCR، ثم يمكن تعديل النص المستخرج يدوياً وترجمته.
- خيارات لغة واجهة التطبيق متاحة بـ 22 لغة، وتظهر أسماء اللغات بلغاتها الأصلية.
- إعدادات التطبيق مخصصة لاختيار لغة الواجهة فقط، ويتم حفظ الاختيار في المتصفح.
- OCR الحالي يستخدم Tesseract.js بلغات العربية والإنجليزية والفرنسية. جودة التعرف قد تختلف باختلاف وضوح الصورة ونوع الخط.


## OCR متعدد اللغات والأنظمة الكتابية
- كتالوج OCR يحتوي على 112 نموذج لغة و33 نموذج نظام كتابة من عائلة Tesseract.
- يمكن تحديد منطقة من الصورة، واختيار حتى 4 لغات أو أنظمة كتابة معاً، والبحث عنها بالاسم المحلي أو الرمز.
- النماذج تُحمّل عند الطلب من CDN وتُخزّن بواسطة Tesseract.js؛ لا تُحمّل كل اللغات دفعة واحدة.
- يجرّب الاستخراج الصورة الأصلية ونسخة محسّنة بالتباين ونسخة ثنائية، ثم يختار النتيجة ذات درجة الثقة/النص الأفضل.
- دعم الخطوط يعتمد على نموذج اللغة وجودة الطباعة؛ الخطوط الزخرفية جداً والكتابة اليدوية والصور منخفضة الدقة ليست مضمونة بنسبة 100%.

## خادم ترجمة اللهجات وDevTerm الآمن
- تُرسل اللهجات ووضع DevTerm إلى `/api/translate` بدلاً من إرسال مفتاح OpenAI من المتصفح.
- الخادم موجود في `server.js` ويستخدم متغير البيئة `OPENAI_API_KEY` فقط. لا تضع المفتاح في GitHub أو في ملفات الواجهة أو في المحادثة.
- ملف `render.yaml` يجهز خدمة Render مجانية مع `OPENAI_API_KEY` كمتغير Secret غير متزامن.
- بعد إنشاء الخدمة، أضف المفتاح من Render Dashboard ضمن Environment، ثم حدّث `api-config.js` بعنوان الخدمة. إعدادات الموقع تبقى مقتصرة على لغة الواجهة.
- الخادم يفرض حدّاً لحجم الطلبات، ويحدد المعدل بـ 40 طلباً لكل 10 دقائق لكل IP، ويقيّد CORS إلى أصل GitHub Pages المحدد.
- لا تعمل ترجمة اللهجات عبر الخادم حتى يُنشر ويُضبط Secret الخاص به.\n- بعد النشر، افحص `/health` وتأكد أن `dialectEngineConfigured` تساوي `true`.\n- لا يوجد مفتاح OpenAI جاهز يمكن إضافته نيابة عن مالك الحساب؛ يجب إنشاء مفتاح خاص بمشروعك وإضافته بنفسك إلى Render Environment كقيمة سرية. راجع [إرشادات حماية مفاتيح OpenAI](https://help.openai.com/en/articles/5112595-best-practices-for-api-key).\n- الترجمة النصية الأساسية تستخدم خدمة Google Translate غير الرسمية؛ لا يوجد ضمان لاستمرارها أو توفرها.
