# SEIF TRANSLATOR

إضافة Chrome / Edge بواجهة بيضاء صغيرة. تتيح اختيار لغة الترجمة من قائمة واسعة من اللغات، وترجمة صفحة الويب أو نص محدد، ورفع صورة من الجهاز لاستخراج النص وترجمته.

## التثبيت
1. نزّل ZIP وفك ضغطه.
2. افتح `chrome://extensions` في Chrome أو `edge://extensions` في Edge.
3. فعّل وضع المطوّر.
4. اضغط تحميل إضافة غير مضغوطة وحدد مجلد الإضافة.
5. ثبّت الإضافة في شريط المتصفح.

## ملاحظات مهمة
- قائمة اللغات تتضمن اللغات التي تدعمها خدمة الترجمة المستخدمة؛ الدعم الفعلي يختلف حسب اللغة والخدمة وليس كل اللغات واللهجات في العالم متاحة.
- الترجمة تستخدم نقطة Google Translate العامة غير الرسمية، وليست تكاملاً رسمياً مع Google Cloud Translation، وقد تتغير أو تفرض حدوداً.
- استخراج نص الصور يستخدم خدمة OCR خارجية تجريبية؛ لا ترفع صوراً سرية أو حساسة. قد تختلف دقة التعرف حسب اللغة وجودة الصورة.
- هذه النسخة تترجم النص المستخرج من الصورة وتعرضه بجانب المعاينة، ولا تستبدل النص داخل الصورة أو تضمن الحفاظ على الخط والألوان بعد الاستبدال.
- ترجمة صفحات الويب تغيّر عقد النص في الصفحة الحالية، وقد لا تعمل على صفحات المتصفح الداخلية أو بعض التطبيقات المعقدة.
