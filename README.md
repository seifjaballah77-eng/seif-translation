# SEIF TRANSLATOR

إضافة متصفح بواجهة بيضاء بسيطة لترجمة صفحات الويب والنصوص المحددة، مع اختيار لغة الهدف ورفع صورة لاستخراج النص منها وترجمته.

## التثبيت على Chrome أو Edge
1. نزّل المشروع بصيغة ZIP وفك ضغطه.
2. افتح `chrome://extensions` أو `edge://extensions`.
3. فعّل **Developer mode / وضع المطوّر**.
4. اختر **Load unpacked / تحميل إضافة غير مضغوطة** وحدد مجلد المشروع.
5. ثبّت الإضافة في شريط الأدوات.

## الاستخدام
- افتح الإضافة واختر لغة الهدف.
- اضغط «ترجمة هذه الصفحة»، أو استخدم قائمة النقر بالزر الأيمن.
- يمكن تحديد نص ثم ترجمته من قائمة النقر بالزر الأيمن.
- من «ترجمة صورة من الجهاز» اختر صورة لاستخراج النص وترجمته.

## ملاحظات الإصدار الأول
- الترجمة تعتمد على خدمة Google Translate غير الرسمية عبر نقطة gtx العامة؛ قد تتغير أو تفرض قيوداً.
- OCR يستخدم واجهة OCR.space التجريبية العامة، وهي محدودة وليست مناسبة للبيانات الحساسة.
- ترجمة الصورة في هذا الإصدار تستخرج النص وتعرض ترجمته؛ لا تعيد رسم النص داخل الصورة بعد. الحفاظ الدقيق على الخط واللون والخلفية يحتاج مرحلة معالجة صور إضافية.
- ترجمة الصفحة تعدّل النصوص في DOM وقد لا تعمل في صفحات محمية أو تطبيقات معقدة، ولا تعيد تحميل النص الأصلي تلقائياً.
